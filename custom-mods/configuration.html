Providers And Voice

Your mod's characters need an AI provider to talk, and optionally voice services. You set these up on your mod's own dashboard. This is separate from the coding agent that builds the mod.

On this page

  • Recommended setup
  • API keys
  • Dialogue model
  • Voice and speech input
  • Optional NPC selection

Recommended Setup

PartRecommendedWhen
DialogueOpenRouter, google/gemma-4-31b-itAlways, or another provider you choose
Voice repliesPocketTTSOnly if you want voice
Speech inputParakeet, push-to-talkOnly if you ask for it
NPC selectionJEV, typesafe/jev-1.13Optional: picks which NPC answers

A fresh template server starts in mock mode, with predictable replies and no network calls, and with voice and NPC selection off. Your agent switches to the provider you chose once your key is saved.

API Keys

  1. Open your mod's dashboard and go to Configuration > API keys.
  2. Paste the key into its slot and press Save keys.

The page shows only Saved or Not set. Keys stay in the mod's private config, never in the database, logs or Git. Each mod has its own keys: do not expect keys from the DwemerDistro launcher or another mod to carry over, and never paste a key into your agent's chat.

Dialogue Model

On Configuration > LLM, choose a Reply mode and model, then press Save LLM settings. Saving never contacts the provider.

Reply modeProvider
openrouterOpenRouter; needs a key
openaiOpenAI or any compatible service
localYour own compatible server
dwemerllmDwemerDistro LLM Studio; load a model there first
mockBuilt-in test replies, no provider

Send test uses the selected Reply mode. mock stays on the server; other modes make one real provider call and show the reply or a short reason, such as HTTP 401 for a refused key. Real calls can cost money, so your agent runs them only when you allow it.

Voice And Speech Input

  • Voice replies. Install and start PocketTTS from the DwemerDistro launcher, enable it on Configuration > Voice, and press Speak to hear a sample.
  • Speech input. With Parakeet, the player holds a key to talk. The words land in the chat box as an editable draft, and nothing is sent until the player presses Enter.
  • Text first. The reply text always appears. If voice fails, the player still gets the text.

Voice counts as working only once someone has heard it, on Speak or in game.

Optional NPC Selection

When the player speaks without picking anyone, the game can offer up to 8 nearby NPCs and JEV picks which one answers. That is all it does today: it writes no reply and runs no actions, and any problem falls back to the default NPC. Turn it on at Configuration > NPC selection. Other JEV decisions are planned.
