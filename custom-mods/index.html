KAGRENAC AI Mod Maker

KAGRENAC AI Mod Maker is a toolkit for authoring your own AI NPC mod. One public repository, Kagrenac, holds both parts: KagrenacServer at the repository root, a small PHP 8.2 and PostgreSQL server that runs inside DwemerDistro, and KagrenacClient in client/, a Windows console client that simulates the game side while you build your port. A player line goes in; an NPC reply and, at most, one safe action come back.

What Kagrenac Is

  • A starting point for your own mod. Make your own copy of the repository, rename it, and replace the console client's simulated game with your engine.
  • Ready-made server features. NPC bios and facts, profiles, memory, session checkpoints, logs, and optional LLM and voice connectors.
  • Mock-first. A fresh install answers with predictable mock replies. The first run needs no LLM provider, API key or voice service.
  • Local by design. The server runs on one PC inside DwemerDistro WSL, or on a trusted local network. The dashboard has no login and the token travels over plain HTTP.

What it is not: Kagrenac is not a playable game client or a plugin for any real game. KagrenacClient has no engine SDK, no game hooks, no microphone capture and no audio playback; its "follow" action is console output only. No game is supported until someone builds and tests a port in that game. Real LLM and voice providers are optional code paths; the smoke checks cover mock mode only.

How A Request Flows

  1. The client sends the player's line to turn.php with a fresh request_id, the session, the NPC and the token.
  2. The server loads that NPC's history, bio and matching facts from its own database.
  3. It asks the mock (or your configured LLM) for a reply, keeps only allowlisted actions, and saves the exchange.
  4. The client checks the request ID and NPC, then shows the subtitle and runs the action through its own allowlist on the game thread.

The full contract is in PROTOCOL.md at the repository root.

Choose An Install Route

RouteServer address
Manual install (main or dev)http://127.0.0.1:19000/custom-mods/KagrenacServer
Launcher Mods > Custom modshttp://127.0.0.1:19000/custom-mods/example-server

Custom mods port: DwemerDistro gives all custom PHP mods one shared port on this PC, CUSTOM_MODS_PORT (default 19000, allowed 19000-19999). Each mod has its own path and database, and official ports such as 8081 do not change. See Ports and branches.

The two routes are separate installs with separate databases: you clone the manual one into custom-mods/KagrenacServer yourself, while the launcher creates and manages custom-mods/example-server from the repository's manifest id. Every route builds the console client separately, from a development copy on Windows; see Before you start.

Guide Map

  1. Installation: ports, installing the server, building the client and pairing them.
  2. Configuration: LLM, API keys, PocketTTS, Parakeet and optional NPC selection.
  3. Data and Memory: NPC bios, facts, profiles, memory and session checkpoints.
  4. Testing: the web conversation tester, events, logs, actions and cancellation.
  5. Porting: replace the console game with your engine in stages with a coding agent, and extend the dashboard.
  6. Updates and Backups: versions, migrations, backups and branch compatibility.
  7. Publishing: your own repository, licence, branding, launcher manifest and private data.
