Installation

Install ExampleServer inside DwemerDistro, build the ExampleMod console client on Windows, and pair them. Everything starts in mock mode, so no provider or key is needed. Allow about 15 minutes.

Before You Start

  • DwemerDistro installed and started. It provides WSL, Apache on port 8081, PostgreSQL and PHP 8.2.
  • Visual Studio 2022 with the Desktop development with C++ workload (MSVC and CMake).
  • Nothing else for the first run. An LLM and voice services are optional and come later.

Both templates offer a main branch (the stable baseline, default) and a dev branch (development). For your own project, clone your own repositories instead; see Publishing.

1. Install The Server

Open a DwemerDistro WSL shell as the dwemer user from PowerShell:

wsl -d DwemerAI4Skyrim3 -u dwemer

DwemerAI4Skyrim3 is an example distro name; yours may differ. Run wsl --list --verbose to see the names installed on your PC, and use yours here and in step 3.

Clone the server into Apache's web root (add -b dev for the development branch), then run the installer:

git clone https://github.com/Dwemer-Dynamics/ExampleServer.git /var/www/html/ExampleServer
cd /var/www/html/ExampleServer
sudo bash scripts/install.sh

The installer creates a private config/config.php with a new random token only if it is missing, creates the example_ai_mod database only if it is missing, sets file permissions and applies migrations. It changes nothing in Apache, PHP or any other product. Running it again keeps your config and data.

Check it:

curl http://127.0.0.1:8081/ExampleServer/health.php
bash scripts/smoke.sh

Health answers with "ok":true, "schema":"007_connector_calls" and "server_version":"0.1.0". The smoke script ends with All checks passed.

Open the dashboard at http://127.0.0.1:8081/ExampleServer/. Control Panel > Diagnostics should say Ready.

Keep it local. The dashboard has no login and no rate limiting; anyone who can open it can change settings and API keys. Do not expose port 8081 beyond your PC or a trusted local network. These templates do not provide a secure online deployment.

If health.php returns 404, check where your Apache serves port 8081 from. To run a second copy with its own database, follow SETUP.md, A separate copy with its own database.

2. Build The Client

In PowerShell on Windows:

git clone https://github.com/Dwemer-Dynamics/ExampleMod.git
cd ExampleMod
powershell -ExecutionPolicy Bypass -File scripts\build.ps1

This builds x64 and x86 into %LOCALAPPDATA%\DwemerDynamics\ExampleMod\build\x64\Release and ...\x86\Release, with config.default.json next to each example_mod.exe. Use the architecture your game uses; the console works with both.

3. Pair The Client

In the WSL shell, write a private client config outside the web root:

cd /var/www/html/ExampleServer
sudo -u dwemer php scripts/pair_client.php --out /home/dwemer/example-client.json

The file is created with mode 0600 and the token is not printed. An existing file is never replaced. The server address is inferred for installs under /var/www/html; elsewhere, add --base-url.

Copy it next to example_mod.exe as config.json. The copy command writes to the current folder, so change to the build folder first. In PowerShell, using your distro name:

cd "$env:LOCALAPPDATA\DwemerDynamics\ExampleMod\build\x64\Release"
Copy-Item \\wsl.localhost\DwemerAI4Skyrim3\home\dwemer\example-client.json .\config.json

Treat both copies like a password, and delete the WSL copy if you no longer need it. config.json is git-ignored.

From the same folder, check the connection and send a first line:

.\example_mod.exe --health
.\example_mod.exe --say "Follow me"

Expected output:

Server is ready.
Versions: client 0.1.0, client baseline baseline-1, server 0.1.0, server baseline baseline-1, schema 007_connector_calls, protocol 1.
[Guide] Of course. Lead the way.
* npc_guide is now following you (simulated).
* Result reported to server: follow_player handled (client-reported, console simulation).

"Following you (simulated)" is console output, not a game engine. WinHTTP error 12029 means the server is not reachable at server_url; 401 unauthorized means the token does not match.

Launcher Route (Pending)

Not released. Launcher custom-mod installation is in draft pull requests Launcher #53, Launcher #54 and Dashboard #28. It also needs DwemerDistro Core changes that are not yet published. Your launcher will not show this option until a release includes it.

As drafted, Mods > Custom mods > Add custom mod takes a public HTTPS repository URL, previews the exact commit, and installs the server in its own folder and database:

  • Folder /var/www/html/custom-mods/example-server, separate from a manual install.
  • Database custom_example_server, and a private config with a new token.
  • Dashboard http://127.0.0.1:8081/custom-mods/example-server/ui/.

The launcher manages the server only. To pair the client with such an install, run pair_client.php from that folder. Details: LAUNCHER_CUSTOM_MOD.md.

Full reference: SETUP.md and the ExampleMod README.
