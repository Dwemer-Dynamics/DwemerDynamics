Get Started

There is no form to fill in and no setup commands to type. Get the template, open your coding agent in it and paste one prompt. The agent asks only for what is missing and runs the setup itself.

What You Need

  • Windows, Git and a coding agent of your choice.
  • DwemerDistro, which runs your mod's server.
  • Your game's mod tools, or a mod loader that supports your exact game version. Your agent works out which.
  • Visual Studio C++ tools only if your mod is a C++ plugin. Script-based mods use their own tools.
  • An AI provider for real conversations: an account and key such as OpenRouter, or a local model. See Providers & voice.

Run Update Distro first. Press Update Distro in the DwemerDistro launcher before your agent deploys anything, including on a fresh install. Your agent then checks that DwemerDistro has the setup tools it needs; the version label alone does not tell you. If something is missing, setup stops without changing anything.

1. Get The Template

Clone the KAGRENAC repository to a folder on Windows, or press GitHub's Use this template and clone your copy. Then open your coding agent in that folder. Your agent creates a separate copy for your mod and works there from then on.

2. Give Your Agent The First Prompt

Paste this exactly as it is. It is the same prompt as in the repository's README:

Read AGENTS.md, PROJECT.md and docs/getting-started.md. Help me build an AI mod.
Reuse what I already told you; ask only for the missing game, starting feature and mod name.
Plan a meaningful gameplay loop and qualify the game's integration before writing port code.
Prepare the server and providers alongside that research. Use in-game text chat by default;
add voice if requested and speech input only if requested. Run the setup, implement, test,
review the actual changes, and fix findings. Keep keys out of chat and preserve existing work.

If you already said which game, feature or name you want, the agent reuses it. Next time, open the agent in your mod's folder and ask it to continue; it resumes from PROJECT.md.

Who Does What

  • You choose the game, the feature and the name; enter API keys on your mod's dashboard; approve anything that costs money or needs your account; and play the result to say whether it works.
  • Your agent plans the gameplay, researches the game, sets up and deploys the server, builds and tests the mod, reviews its own changes and records progress in PROJECT.md.

Two different AIs. Your coding agent builds the mod. The dialogue model you set up on the mod's dashboard writes the characters' replies; an optional, separately configured text-to-speech service supplies their voice. Neither is your coding agent, and your agent never needs your provider keys in chat.

What Your Agent Sets Up

These are one-time setup steps the agent runs from your mod's folder. They are not something players repeat each session.

StepWhat it does
CreateCopies the template into a new, independent repository for your mod, with its own id and name.
DeployInstalls your mod's committed code as its own server in DwemerDistro, keeping existing settings and data.
ConfigureChooses the dialogue provider, voice and allowed actions for that server.
PairWrites the game mod's private connection file, without showing its token.

The game side is built by its own route once the game has been checked; see Game integration. The exact commands are in docs/getting-started.md.

Where Things Live

WhatWhere
SourceYour mod's repository, checked out on Windows. The agent works here.
BuildsOutside the source, by default under %LOCALAPPDATA%\DwemerDynamics\Kagrenac\projects\<id>. You can choose another folder.
Game sideThe game's mod folder or loader profile, with the private connection file.
ServerNew mods: /var/www/html/<Name>Server in DwemerDistro, for example http://127.0.0.1:19000/MyModServer, with its own database. An existing install keeps the path DwemerDistro has on record for it.

All custom mods share one port on this PC, CUSTOM_MODS_PORT (default 19000, allowed 19000-19999). Update Distro keeps your port, so addresses stay the same.

Every mod has its own server folder and database. Never point two mods at the same database. Older installs under /custom-mods/<id> keep working.

Legacy Template Installs

Earlier guides installed the template server on its own, as /custom-mods/example-server through the launcher or /custom-mods/KagrenacServer by hand. Those installs keep working and keep their data. They contain no game mod. For the manual route, maintenance and removal, see SETUP.md and LAUNCHER_CUSTOM_MOD.md.
