Characters And Memory

Your mod's server keeps what characters know in its own database. Some of it you write, some the game reports, and some the AI writes down as notes. Knowing which is which tells you what a save or a checkpoint changes.

Conversation historySaved after each exchangeOne session and character
Memory notesWritten by the AI, if turned onOne session and character

A session usually stands for one save game; the game mod decides. Characters need a stable ID so their bio and history follow them. What the game reports is covered in Game awareness.

Bios And Facts

Edit characters on Configuration > NPC bios. Give each a current goal, one or two relationships and what they are doing now. Keep bios short, factual and limited to what the character would plausibly know. Facts can belong to one character or to everyone.

How Facts Are Found

Each turn, the server matches words from the player's line against your facts and adds the best few, plus the bio. This is keyword matching: "market" finds a market fact, but "bazaar" does not. Optional vector search can find related wording with a real embeddings service; see Memory. Control Panel > Logs shows what each turn retrieved.

Profiles

A profile on Configuration > World & Behavior > Profiles gives one or more characters their own instructions, and optionally their own model or voice. Characters without a profile use the default profile if you mark one, otherwise the main settings. A profile cannot send your key to a different provider.

Memory

Memory is optional and off by default. Turn it on at Configuration > AI & Voice > Memory settings:

  • Enabled gives each turn this session's summary and recent notes.
  • Automatic notes and Automatic fact proposals make extra AI calls after each reply, which may cost money. Proposed facts wait on Roleplay > Memory until you approve them.
  • Vector search for facts finds facts by meaning instead of exact words, using an embeddings service you configure. The built-in mock provider only matches shared words. Press Reindex after turning it on.

One rule: remember what the game observed, never what a reply claimed.

Checkpoints

A checkpoint on Roleplay > Checkpoints saves one session's conversation and notes so you can roll back to it, for example to match an earlier game save. It lives inside the same database, so it is not a backup. For backups, see Updates & recovery.
