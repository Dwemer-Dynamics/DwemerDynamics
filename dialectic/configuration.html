Dialectic Configuration

Most Dialectic behavior is owned by DialecticServer. The in-game MCM is reserved for settings that need to affect the Fallout plugin directly.

Configuration Hub

Open Dialectic from the Dwemer Dashboard, then select Configuration. The Configuration Hub keeps the main server systems together.

Dialectic NPCs

NPC profiles contain identity, biography, personality, voice, race, gender, SPECIAL, skills, equipment, inventory, factions, relationships, memories, and per-character behavior.

Game telemetry creates profiles automatically when suitable actors are activated. Profile locks protect hand-edited characters from bulk cleanup.

Each profile also has a History view for events routed to that character. You can filter recent events, inject new context while an NPC is outside the current scene, include additional NPC recipients, and delete entries. Deleting a shared event removes it from every listed recipient.

Global Settings

Global Settings control context history, prompt sections, rechat mode, strict targeting, connector roles, filters, memory behavior, relationships, combat barks, and other server-wide defaults.

Context Selections let you disable expensive or unwanted prompt sections without disabling the game telemetry that maintains the underlying data.

Presets save these server-wide settings as a named set. Default is the standard setup, and Local LLM is tuned for smaller models running on your own machine. Apply loads the selected preset, Save New stores your current settings under a new name, and Overwrite updates the selected preset with them.

Global presets carry general settings only. They do not include API keys or other credentials, provider or server URLs, prompts, connector assignments, profiles, relationship preservation, or profile memory settings. Applying a preset leaves all of those as they are.

Profiles

Profiles group NPC behavior, prompts, model assignments, narration, rechat rounds and probability, memory options, and other roleplay rules. A character can inherit these values while retaining specific NPC overrides.

The effective order is global defaults, selected profile settings, then explicit NPC settings.

LLM, TTS, STT, And API Keys

Connector pages define the services Dialectic uses for language models, character voices, player voices, and microphone transcription. API Keys stores credentials separately so connectors can reference a shared key.

Global connector slots assign dedicated models to summaries, memories, profiles, Director Mode, relationships, world knowledge, and scene classification.

OpenRouter is optional. Follow Use Your Own LLM Provider to connect Dialectic to another compatible hosted or local service.

To run a model on your own PC, the LLM page has a guided local-model setup that finds your local server, lists the models it is serving, and saves the connector for you. See Local Models.

Player And Narration

The Player page manages the detected player profile and optional player voice. The Narration page owns narrator enablement, welcome recaps, random narration, inline narration routing, asterisk filtering, and narrator context rules.

PipVision

PipVision turns what you are looking at in game into visual context, so characters can respond to a scene rather than to words alone. Enable it here, pick the connector that reads the captures, and choose how much of that context reaches prompts.

The gallery keeps recent captures, so you can see exactly what a character was shown and remove anything you would rather not keep. See Fallout Settings for the in-game hotkey.

World Knowledge, Biographies, And Descriptions

World Knowledge gives characters curated setting information. NPC Biographies imports fixed actor identity data. Descriptions adds readable context for items, locations, races, factions, and other Fallout records.

These systems use structured database records that can be uploaded, reviewed, exported, and updated independently.

Action Editor

The Action Editor controls which actions can be offered to the LLM, their prompt wording, targeting rules, parameters, return messages, cooldowns, and game-side action name.

Keep actions disabled until their Fallout implementation and required ESP records are present.

Prompts Manager

Prompts Manager owns the instruction blocks used for dialogue, rechat, narration, Director Mode, memories, dynamic profiles, diaries, actions, and related systems.

Profile and NPC prompt-head overrides can specialize behavior without replacing the complete shared prompt pipeline.

TTS Studio

TTS Studio maps Fallout voice types and uploaded samples to supported voice-cloning connectors. Use its play and refresh controls to verify a voice before testing it in game.

Events, Memories, And Control Panel

Events & Memories shows game events, AI responses, memories, and active quests. The Control Panel exposes the response queue, audio cache, database manager link, audits, and service health tools used during troubleshooting.

Playthrough Saves

Keep a separate AI history for each character. These saves hold Dialectic conversations, memories and character state; keep saving your game normally too.

  • Choose a playthrough: Use the picker on the server home page to switch or start a new playthrough. Read the save details before choosing.
  • Save and transfer: Open Playthrough Management to manage your saves. Download a save for backup or import one when moving your AI history.
  • Automatic switching: Turn on Automatically switch playthroughs in the storage controls to match your loaded character. This is off by default. Reload your game save after enabling it and follow any prompt to associate an existing playthrough.
  • Before switching: The current AI progress is saved before the other playthrough is loaded.
  • Loading an older game save: AI history follows the game timeline. Automatic recovery saves use the Game days behind threshold. Check the recovery message and saved playthroughs if you need the later AI state.
  • Cleanup: Storage and Cleanup lets you choose which categories to clean and how old entries must be. Event cleanup is off by default. Review the category carefully before deleting anything.

Profile Updates And Event Filters

Choose how often characters develop and which events they use in conversation.

  • Profile timing: Set the dynamic-profile interval in the web settings, in game hours. Check the selected profile and any NPC override when one character needs a different schedule. The old game-menu timer is no longer the place to set it.
  • Event Type Filter: Tick an event type to exclude it from conversation context. Add a custom event type when it is not listed. This does not delete the saved event.
  • Voice: See Voice Tools for voice effects and pronunciation changes.

PipVision Scene Descriptions

When an NPC describes a PipVision capture, their personality and speech style help shape what they say.

  • The configured image-to-text prompt still controls how the scene is read.
  • See PipVision controls for capturing a scene.
