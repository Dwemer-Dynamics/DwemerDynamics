Dialectic Configuration

Most Dialectic behavior is owned by DialecticServer. The in-game MCM is reserved for settings that need to affect the Fallout plugin directly.

Configuration Hub

Open Dialectic from the Dwemer Dashboard, then select Configuration. The Configuration Hub keeps the main server systems together.

Dialectic NPCs

NPC profiles contain identity, biography, personality, voice, race, gender, SPECIAL, skills, equipment, inventory, factions, relationships, memories, and per-character behavior.

Game telemetry creates profiles automatically when suitable actors are activated. Profile locks protect hand-edited characters from bulk cleanup.

Global Settings

Global Settings control context history, prompt sections, rechat mode, strict targeting, connector roles, filters, memory behavior, relationships, combat barks, and other server-wide defaults.

Context Selections let you disable expensive or unwanted prompt sections without disabling the game telemetry that maintains the underlying data.

Profiles

Profiles group NPC behavior, prompts, model assignments, narration, rechat rounds and probability, memory options, and other roleplay rules. A character can inherit these values while retaining specific NPC overrides.

The effective order is global defaults, selected profile settings, then explicit NPC settings.

LLM, TTS, STT, And API Keys

Connector pages define the services Dialectic uses for language models, character voices, player voices, and microphone transcription. API Keys stores credentials separately so connectors can reference a shared key.

Global connector slots assign dedicated models to summaries, memories, profiles, Director Mode, relationships, world knowledge, and scene classification.

Player And Narration

The Player page manages the detected player profile and optional player voice. The Narration page owns narrator enablement, welcome recaps, random narration, inline narration routing, asterisk filtering, and narrator context rules.

World Knowledge, Biographies, And Descriptions

World Knowledge gives characters curated setting information. NPC Biographies imports fixed actor identity data. Descriptions adds readable context for items, locations, races, factions, and other Fallout records.

These systems use structured database records that can be uploaded, reviewed, exported, and updated independently.

Action Editor

The Action Editor controls which actions can be offered to the LLM, their prompt wording, targeting rules, parameters, return messages, cooldowns, and game-side action name.

Keep actions disabled until their Fallout implementation and required ESP records are present.

Prompts Manager

Prompts Manager owns the instruction blocks used for dialogue, rechat, narration, Director Mode, memories, dynamic profiles, diaries, actions, and related systems.

Profile and NPC prompt-head overrides can specialize behavior without replacing the complete shared prompt pipeline.

TTS Studio

TTS Studio maps Fallout voice types and uploaded samples to supported voice-cloning connectors. Use its play and refresh controls to verify a voice before testing it in game.

Events, Memories, And Control Panel

Events & Memories shows game events, AI responses, memories, and active quests. The Control Panel exposes the response queue, audio cache, database manager link, audits, and service health tools used during troubleshooting.
