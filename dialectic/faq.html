Dialectic FAQ

Common setup and troubleshooting questions for Dialectic and DialecticServer.

FAQ

Do I have to use OpenRouter?

No. OpenRouter is an easy starting point, but Dialectic can connect to other compatible hosted or local services. Follow Use Your Own LLM Provider for the setup.

Where do I download Dialectic?

Dialectic is on Nexus Mods. Take the main archive and the separate Custom INI archive, then follow the installation guide.

Does Dialectic require Tale of Two Wastelands?

No. Fallout: New Vegas is the base game requirement. Tale of Two Wastelands is supported, but Dialectic.esp only requires FalloutNV.esm.

Why is the Dialectic MCM missing?

Install MCM, MCM Extender, ShowOff xNVSE, and UIO. Confirm Dialectic.esp and Data/MCM/Dialectic.json are enabled, then load the save and allow MCM time to register.

Why do the hotkeys do nothing?

Hotkeys are intentionally unbound by default. Bind Chatbox, Voice Chat, PipVision, Manual AI Activate, mode/model menus, or Halt AI Actions from the Dialectic MCM.

Why do I get no player voice or NPC response?

First confirm the input appears in Events & Memories. If it does not, check plugin connection and targeting. If it does, inspect LLM output, TTS jobs, plugin output, and the in-game queue in that order.

Why is an NPC using the default TTS voice?

The actor needs a detected Fallout voice type, a real installed sample, and a connector capable of using that sample. Check the NPC profile, TTS Studio sync status, voice-sample upload logs, and the active TTS connector.

Why are there no subtitles?

Enable Show AI Subtitles in the Behavior MCM page. Dialectic uses Fallout's passive subtitle area and prefixes generated lines with the speaker name.

Why does dialogue stop when I open the Pip-Boy?

If Pause Dialogue in Menus is enabled, current audio, subtitles, lip animation timing, and queued lines pause until the blocking menu closes. This is a pause, not Halt AI Actions.

Why did a creature speak?

Normal automatic activation is limited to supported humans, non-feral ghouls, super mutants, and robots. Check Add All Races, manual activation, and whether the actor's race data was resolved correctly.

Why is rechat not happening?

Check the active profile's rechat rounds and probability, the global rechat mode, strict targeting, nearby people, scene freshness, combat/menu/sneak gates, interruption state, and whether the previous response queue fully completed.

Why are actions missing or not running?

Actions must be globally enabled, allowed for the current response type, present in the prompt, returned through the structured response schema, routed by the server, and implemented by the game plugin. Some movement actions also require records in Dialectic.esp.

I loaded an older save and lost recent events

Loading an older game save rolls back playthrough events and memory data newer than the loaded save timestamp, then cancels stale dialogue and rechat. Check the recovery notice and Playthrough Saves for the later AI state. Automatic recovery saves depend on the configured game-day threshold.

The game is lagging after several conversations

Use Halt AI Actions, save the plugin log, and inspect task, audio, lip animation, actor scan, and rechat timing. Make sure the server and plugin are current before reporting the diagnostic bundle.

Do server setting changes require a game restart?

Most server settings apply to the next request. Native plugin, ESP, script, MCM, and INI updates generally require restarting Fallout.

Where are the logs?

See the Dialectic Log Files guide for plugin, JIP LN, server, connector, and launcher diagnostic paths.

How Do I Keep Separate AI Histories?

Use Playthrough Saves for each character. Automatic switching is optional and starts off.

  • After a rewind: Check the recovery notice and the saved playthroughs before assuming the later AI state is lost.
  • No response: Check that the in-game interaction switch is On, then check the server connection and chosen services.
  • Microphone: Check its own recording and mute controls. Turning interaction Off is not the same as muting.

Why Is Shared Dialogue Silent?

Check the connection status in the dialogue-sharing controls.

  • Confirm the host still has a session running and that the copied code belongs to that session.
  • Close MCM after joining and wait for the host to speak. Sharing does not create a shared Fallout world.
  • See Dialogue Sharing for the host and listener steps.
