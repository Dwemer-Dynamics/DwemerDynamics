Mount & Blade II: Bannerlord · Reign

Settings and the Control Center

Find the right settings screen and understand provider choices, costs and privacy.

Development guide · November 24, 2026 · Edition notes

Browse A–Z · Search shortcut: Ctrl/⌘ K

Which settings window to use

#

Use MCM inside Bannerlord for game-side feature and execution switches. Use the Control Center for providers, server-side gameplay options, images, memory, backups, and advanced diagnostics. Arena Overhaul has its own MCM section.

Use the installed launcher's managed server on/off and Control Center controls. An ordinary browser tab or an old batch-file instruction is not necessarily the supported lifetime owner for your installed edition. Do not close or restart the server during an important request or save unless you are deliberately recovering from a problem.

Execution and server connection switches

#

Execute Diplomacy Actions, Execute Strategy Plans, Execute Internal Politics Actions, and Execute Conversation Actions determine whether their supported plans may create real game effects. Enable Campaign Command Engine governs persistent NPC orders. Enable Ruler-Driven NPC Diplomacy enables autonomous foreign-ruler work.

Use Local Bannerlord Reign Server, Local Server URL, and Receive Server Action Commands connect the native game with its server. A working chat with action execution turned off can still produce discussion without the transfer or order you expected. Correct the relevant setting deliberately; do not enable every debug control as a general repair.

The utilities Open Party Chat and Open Correspondence provide alternatives to backslash (\) and Ctrl+M. Alt+A opens actions within a supported, ready Reign conversation rather than globally on the map. Show Debug Messages is informational; Enable Debug Controls exposes tools that can change a campaign or generate provider work. They are not required for ordinary play.

Test tools can alter state or consume provider allowance. They are not a way to unlock the normal game. Character Editor revisions can change a campaign and may have native effects; inspect the exact change and confirmation rather than treating it as an in-character ability.

Make editor changes with the intended campaign and save point active. If a native effect is waiting for confirmation, reopen that same save so Reign can finish recording it. When using an editor undo, review the specific edit it refers to. Other recorded exchanges and newer edits can remain in the character history.

War economy and clan trade settings

#

In the Control Center open Options, then War economy. You can adjust troop wages, recruitment and upgrades, village food output, garrison wage and food savings, automatic spending reserves, and raid food disruption. A disabled group keeps the values you entered. For wages and upgrades, change the cost rules. For garrisons, change the stationary wage and food savings. Spending reserves protect money needed for upcoming obligations. The Fund Local Household Stipends switch is in Reign's in-game MCM.

  1. Open Control Center → Options → War economy → NPC Clan Trade.
  2. Turn on Enable NPC clan caravans or Enable NPC clan convoys. Sea convoys require War Sails.
  3. Set the formation price and per-clan limit for each route. An eligible clan must cover the fee within the shared cash cap and keep its military reserve before the daily chance applies.
  4. Select Save economy options to apply your changes.

If your installation only shows Enable NPC Caravan Investment Pilot in MCM, that switch runs the older land-only route with named captains.

Provider choices, costs, and privacy

#

Keep cloud dialogue and cloud image configuration separate. A provider can be configured yet temporarily unavailable, out of allowance, or unable to serve the selected model. Use the supported saved route and its diagnostic feedback.

In LLM Backend and Models, select the text provider and model you want. For Ollama Cloud, use an Ollama Cloud key, which can come from a matching global key or your Reign-only setting. If the model returns a usable speech-only reply, Reign can display and remember the words. Actions, consent, relationship changes, and special event outcomes still need a reply the game can process for effects. Check the recorded result before retrying important terms. If your model repeatedly returns only speech when you need actions, select another supported model.

If your installation has DwemerDistro Global API Keys connected, Reign can use a matching key for that provider and endpoint. Choose a key when there is more than one match, or use Save Reign-only key to override it for this slot. Clearing an override can return the slot to its eligible global key. On setups without the shared store, use the ordinary local key field and Save controls.

Cloud requests send relevant game/conversation context to the selected provider. API keys remain server-side rather than entering the Bannerlord client. Reign's local memory worker does not mean dialogue never leaves the computer. Optional external vector storage has a different role from the dialogue provider; raw campaign prose is not simply the vector itself.

Turn detailed conversation capture on only when you need it and understand what is stored. Logs and exported diagnostic payloads can contain private fictional character information and your own chat text. Avoid sharing a whole settings file when a redacted error and selected report will do.
