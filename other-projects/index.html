Other Projects

Modding tools and experiments from Dwemer Dynamics that sit outside the AI game mods. Each project has its own page here and its own public repository.

Kosmokrator

Dominions 6 / Modding tool

Make nations and maps for Dominions 6 with Codex or Claude Code, then review and export them in your browser.

  • Make nations and maps, or import an existing mod.
  • Browse units and edit their stats and traits.
  • Check for problems and export a mod or map bundle.

Read the Kosmokrator page README on GitHub

Kenogenesis

Conquest of Elysium 5 / Modding tool

Make classes and factions for Conquest of Elysium 5, then review, check and export them in your browser. Codex or Claude Code is optional.

  • Make classes and factions, or import an existing mod.
  • Browse and edit units, rituals, items and classes.
  • Check for problems and export a mod ZIP.

Read the Kenogenesis page README on GitHub
