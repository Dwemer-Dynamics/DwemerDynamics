CHIM Log Files

When CHIM is failing, the fastest fix is usually finding the right log first instead of guessing. This page keeps the useful log locations, and names the buttons the way HerikaServer and the DwemerDistro launcher label them.

Log Files

AIAgent Log

This is the main first-stop log for the Skyrim plugin side.

AIAgent.log is commonly found in:

C:\Users\YOURUSER\Documents\My Games\Skyrim Special Edition\SKSE

C:\Users\YOURUSER\Documents\My Games\Skyrim.INI\SKSE

If CHIM is not connecting, not sending requests, or not responding correctly in-game, this is usually the first log to read.

Papyrus Log

Use the Papyrus log when the issue feels like a Skyrim scripting problem instead of a server or provider problem.

C:\Users\YOURUSER\Documents\My Games\Skyrim Special Edition\Logs\Script\Papyrus.0.log

This is useful for tracking script errors, missing functions, and plugin-side events that never reach the CHIM server cleanly.

CHIM Server Logs

There are two ways into the main CHIM server logs:

  1. HerikaServer: Control Panel then the Server Logs tab.
  2. Distro Launcher: open the LOGS tab, click Generate Distro Debugging Logs at the top of the page, and confirm when prompted.

The HerikaServer side embeds the CHIM distro debugger from the dashboard. The launcher writes its diagnostic file to:

Desktop\DwemerDistro-Diagnostics\diagnostics-YYYYMMDD-HHMMSS.txt

The CHIM log viewer reads the HerikaServer log folder and shows these files:

  1. apache_error.log
  2. chim.log
  3. output_from_llm.log
  4. context_sent_to_llm.log
  5. output_to_plugin.log
  6. stt.log
  7. vision.log
  8. debugStream.log
  9. context_sent_to_llm_fast.log
  10. monitor.log
  11. service.log

The launcher's LOGS tab also has a LIVE LOGS section below the diagnostic button. Each button there opens one service log live in a terminal window: Dwemer Distro XTTS, Chatterbox, PocketTTS, MeloTTS, Piper, LocalWhisper, Parakeet, and Apache. Use these when the diagnostic file and the server log views are not enough and you want to watch a single service while you reproduce the problem.

Reporting Background Life And Traditional Quests Issues

Include enough detail to show which character or quest was involved. Gather this before posting:

  1. AIAgent.log from the location above.
  2. A DwemerDistro diagnostic file, made in the Distro Launcher from the LOGS tab with Generate Distro Debugging Logs, confirming when prompted.
  3. The NPC name or quest name the problem happened with.
  4. The quest stage or action that failed, and what you expected to happen instead.
  5. For Background Life, the NPC's Background Life Goals and their recent history entries from around the time it went wrong.

Both systems are still in beta, so the surrounding history helps show what led to the problem.
