CHIM Skyrim Settings

This page mirrors the current CHIM MCM inside Skyrim. Each section below is one real MCM page, with the current option labels grouped the same way they appear in game.

Use this when CHIM is already installed and you want to tune how it behaves during actual play.

Skyrim Settings

Main

This is the main control page for how you talk to CHIM, open its wheels, and toggle a few core gameplay features.

Communication and wheel hotkeys

These are the fast-access bindings for talking to CHIM and opening its main wheel menus.

  • CHIM Chat: Opens the Prisma text chat so you can type to AI NPCs without leaving the game.
  • Voice Chat: Push-to-talk speech input for AI NPC conversation and book summaries.
  • Master Wheel: Quick access wheel that opens Roleplay, Settings, Mode, or Soulgaze.
  • Roleplay Wheel: Opens diary, gather, update, wait/follow, stop AI, and background-life style actions.
  • Settings Wheel: Lets you assign profiles when targeting an NPC, or switch LLM setup when not targeting one.
  • Mode Wheel: Cycles between Standard, Whisper, Director, Cheat Mode, Auto Chat, Event Inject, and Inject & Chat.
  • Soulgaze Wheel: Opens the in-game image capture options for full Soulgaze, NPC photos, or raw upload.
  • Manual AI Activate: Manually turns AI control on or off for the targeted NPC, or nearby NPCs if nothing is targeted.
  • Halt AI Actions: Immediately stops CHIM AI actions for the targeted NPC or all nearby NPCs.

Core toggles and runtime settings

These are the main on/off gameplay switches for what CHIM is allowed to do once it is running.

  • Enable AI Actions: Allows CHIM NPCs to perform in-game actions instead of only talking.
  • Enable Animations: Lets AI NPCs use animations during interaction.
  • Player TTS for Traditional Dialogue: Uses your selected PlayerTTS voice for normal Skyrim dialogue menus, if that feature is enabled on the web side.
  • Soulgaze HD Mode: Uses the higher-end Soulgaze capture path. VR users generally want this off.
  • Connection Timeout (seconds): How long CHIM waits on the server before giving up on a request.

Auto Activate

This page controls when CHIM automatically picks NPCs up into the active AI system and how far speech awareness reaches around you.

Activation rules

  • Enable Auto Activate: Turns automatic nearby NPC activation on or off.
  • Interior Auto Activate Distance: Distance for automatic activation inside interiors.
  • Exterior Auto Activate Distance: Distance for automatic activation outside.

Speech awareness distances

These settings are about who can realistically hear speech in the current scene, not just who becomes an AI agent.

  • Interior Spatial Hearing Distance: Indoor hearing range for conversation awareness checks.
  • Exterior Spatial Hearing Distance: Outdoor hearing range for conversation awareness checks.

Who can be auto-added

By default, Auto Activate is more conservative. These switches make it much broader.

  • Add Hostile NPCs: Lets Auto Activate include hostile NPCs as well.
  • Add All races: Lets Auto Activate include all races, including animals. This can be unstable.

Behavior

This page tunes how AI NPCs behave over time, how they move in scenes, and how talk-heavy they stay during combat.

Timers

These drive recurring background behavior and automatic profile changes.

  • Bored Event Timer (seconds): How often bored-style events can potentially fire.
  • Dynamic Profile Timer (minutes): How often dynamic profiles can refresh from recent events.

NPC Behavior

These settings change how NPCs physically place themselves around you and whether CHIM tries to avoid breaking delicate scenes.

  • NPCs Sandbox Near Player: Makes NPCs subtly move around the player to make conversations easier to follow.
  • NPCs Walk To Target: Makes NPCs walk toward the person they are talking to.
  • Seat Conversation Camera: When seated in first person, rotates the camera toward the active speaker.
  • NPC Scene Safety: Prevents AI NPCs in traditional dialogue scenes from auto-responding and breaking those scenes.

Combat Settings

These decide how talkative CHIM stays once combat starts and whether it swaps to bark-style combat chatter instead.

  • Allow combat dialogue: Enables AI dialogue during combat.
  • Clear dialogue entering combat: Immediately cancels active dialogue when combat begins.
  • Enable Combat Barks: Allows AI agents in combat to shout taunts and battle cries.
  • Combat Bark Timer (seconds): How often combat barks can trigger during active combat.

Sound

This is the main page for voice playback, lip sync, audio positioning, microphone behavior, and the current recording device.

Basic

These settings control overall AI voice loudness and how voices fade or position around the player.

  • AI Voice Volume: Main volume level for AI NPC speech.
  • AI Voice Distance Scale: Adjusts how voice loudness behaves with distance.
  • Interior Playback Dropoff (%): Controls how aggressively indoor voice playback falls off with distance.
  • Exterior Playback Dropoff (%): Controls how aggressively outdoor voice playback falls off with distance.
  • Enable 3D Audio Playback: Keeps voice playback spatial instead of flattening it into simple 2D sound.
  • Camera Based Audio: Makes 3D voice direction follow the camera instead of player facing. In VR, CHIM uses the HMD position and orientation so spatial voices follow where your head actually is.

Advanced

These settings are the cleanup and fine-tuning layer for clipped silence, lip movement, pause behavior, and STT override.

  • Skip milliseconds at begining: Cuts silence from the start of generated audio clips.
  • Skip milliseconds at end: Cuts silence from the end of generated audio clips.
  • 3D Sound Invert Heading: Tries the opposite heading if front/back 3D audio sounds wrong.
  • Resolution of Lip Animations: Controls how detailed lip motion updates are.
  • Intensity of Lip Animations: Controls how strongly mouths open during speech.
  • Pause Dialogue on Game Pause: Stops CHIM dialogue while the game is paused.
  • Use WebSocket STT: Uses the separate WebSocket STT path instead of the normal server-side STT path.

Open Mic Settings

These settings are only for open-mic speech input. They decide when recording starts, stops, and how you can silence it quickly.

  • Enable Open Mic: Starts recording automatically when your voice crosses the detection threshold.
  • Voice Detection Sensitivity: Higher values require louder speech before open mic starts listening.
  • End of Sentence Delay (seconds): How long CHIM waits after speech stops before ending the recording.
  • Mute Open Mic: Hotkey that temporarily mutes open mic.

Recording Device

This is just a read-only status line so you can confirm which Windows microphone CHIM is currently resolving.

  • Current Device: Shows the active recording device name CHIM is currently using.

Prisma UI

This page controls the hotkeys used to open CHIM's Prisma panels. The main CHIM menu can launch the chat, Context Window, actions, diaries, Background Life, CHIM NPCs, status panels, and AI Quest Manager from one place.

Hotkeys

  • Master Menu: Opens the main CHIM launcher for all Prisma panels and their layout settings.
  • CHIM Chat: Opens Prisma chat input so you can type a message and send it without leaving the game.
  • Chatbox View: Opens the standalone Context Window, which shows the newest dialogue and world events while you play.
  • Actions Menu: Opens the Prisma action panel for in-game AI interactions and commands.
  • Status, Minihud, Terminator Views: Cycles between the Prisma status displays and closes them on another press.
  • History/Diaries: Cycles between conversation history and diaries, then closes them.
  • Browser (Beta): Opens the in-game browser view for the HerikaServer web UI.
  • Logs View (Beta): Opens the Prisma logs and diagnostics view.

CHIM Chat controls

  • Mode: Switch between Standard, Whisper, Close, Shout, Narrator, Director, Cheat Mode, Auto Chat, and event-injection choices.
  • Profile and LLM: View the targeted NPC's profile, assign a different one, choose a conversation model, or use the profile's Random LLM setting.
  • Rechat Mode: Change Tight, Conversational, Group, or Random follow-up behavior without opening the web interface.
  • Compact Chat: Uses a shorter, cleaner conversation history when building the next response.
  • Recent Context: Shows the newest dialogue and important world events below the chat panel.
  • Book summaries: Text chat can summarize the book currently open in Skyrim when used from the appropriate reading context.

Prisma UI Settings

  • Scale interactive Prisma menus from 100% to 200% for larger screens or easier reading.
  • Choose where the Context Window and status panels appear, then reset the layout if needed.

Action confirmations

  • Actions configured to require permission open a Prisma confirmation dialog before the game command runs.
  • Accepting executes the queued action. Declining cancels it completely and does not request a replacement AI response.
  • Confirmation policy is configured per action in the web Action Editor.

AI Agents

This page is the live agent management page. It is less about permanent settings and more about what is active around you right now.

Agent Management

These controls do bulk add and remove work on the current live agent list.

  • Add all current AI Agents: Adds almost all nearby NPCs into the AI system right away.
  • Remove All AI Agents: Removes all currently active AI agents from the system.

Active AI Agents

This section is partly dynamic. It builds itself from the AI agents currently active in your game.

  • Remove: [NPC Name] Removes that specific current AI agent.
  • No AI agents active or Total Active Agents: [count] shows the current agent status for the page.

Nearby Available NPCs

This section is also dynamic. It is generated from nearby NPCs who are not currently active AI agents.

  • Refresh Nearby NPCs List: Rebuilds the nearby list.
  • Add: [NPC Name] Adds that nearby NPC into the AI system.
  • No nearby available NPCs or Available NPCs: [count] shows the current nearby addable status.

Tools

This page is for one-time or occasional sync tools that make certain CHIM features work better.

  • Send faction and location info: Sends faction and location data to the server so travel and world-awareness features work better. The in-game help says this usually only needs to be done once per playthrough.
  • Send all voice samples to server: Uploads all available voice samples so the server has the voice data it expects.
