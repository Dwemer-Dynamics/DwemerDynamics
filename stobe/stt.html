STOBE Speech-to-Text

Speech-to-text turns your microphone recording into words your selected character can say.

Set Up Your Microphone

Set up transcription on the server, then bind the recording key in Kenshi.

  • Service: Quickstart selects Parakeet for local transcription. Install and start that component in DwemerDistro, or choose a hosted STT provider and save its required key.
  • Test: Open the server Speech-to-Text settings and test the selected service before troubleshooting the game.
  • Microphone: Check the intended input device in Windows and allow microphone access for desktop apps.
  • Key: Open STOBE Plugin Settings and bind Push-to-Talk Key. Select a player character, hold the key to speak, then release to send.
  • Text only: Disable the push-to-talk key if you prefer the Chat Box.

If Your Words Do Not Appear

Check recording, transcription and the reply separately.

  • Confirm Windows can hear the microphone and that a player character is selected.
  • Confirm the chosen STT service is running and passes its server test.
  • If your words appear but no reply arrives, check the interaction switch and LLM settings.
  • Use Generate Logs when reporting the problem.
