STOBE Large Language Model Services

StobeServer can use several hosted and local AI services. OpenRouter is the simplest place to start, and profiles let you keep four response choices ready at once.

Response Modes

Each profile has four response slots. Switch between them from the in-game Chat Box without rebuilding the profile.

  • Standard: The normal choice for everyday dialogue. New profiles use GLM 4.7.
  • Fast: Prioritizes quicker replies. New profiles use Gemini 2.5 Flash Lite.
  • Powerful: Use when a scene needs more careful reasoning. New profiles use GLM 5.2.
  • Experimental: A spare slot for trying another model. New profiles use DeepSeek V4 Pro.

QuickStart fills these defaults for new installs. Existing profile choices are not replaced during updates.

Services

OpenRouter

OpenRouter is the easiest general starting point for most STOBE users. It gives you one account that can access many different AI models, so you can try options without constantly rebuilding your setup.

OpenRouter

OpenAI

OpenAI connects STOBE straight to GPT models. It is a simple choice if you already use OpenAI and want a more direct setup instead of browsing lots of model options.

OpenAI

Google

Google uses Gemini models for your STOBE conversations. It is another mainstream cloud option if you prefer Google's AI tools or want to compare its style against OpenAI and OpenRouter.

Google AI Studio

Groq

Groq is mainly about speed. It can make STOBE feel more responsive because replies tend to come back quickly, which some players prefer for fast back-and-forth dialogue.

Groq

Nano-GPT

Nano-GPT is another hosted service that gives you access to AI models without running them on your own PC. Think of it as an alternative provider if you want more choice outside the biggest platforms.

Nano-GPT

Player2

Player2 lets STOBE use the Player2 app running on your computer. Choose Player2 in QuickStart if that is the service you want for all response modes.

Player2 Local Endpoint

Custom

Custom is the fallback option for bringing in some other AI service that is not already listed here. Use it when you already know your provider supports OpenAI-style connections and you want to plug it into STOBE manually.

OpenAI-Compatible Chat API
