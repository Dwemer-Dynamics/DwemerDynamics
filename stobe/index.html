STOBE

STOBE is the Kenshi-side AI framework overhaul. It focuses on agentic characters, dynamic dialogue, narrator support, and a shared DwemerDistro service stack tuned for Kenshi.

Overview

What STOBE Is For

  • AI dialogue for Kenshi characters and creatures.
  • TTS support so characters can actually sound present in the scene.
  • Configuration that supports heavier roleplay instead of a single rigid script.

Core Features

  • Agentic Characters: NPCs can react to changes in the world with more autonomy.
  • Kenshi-specific Flavor: Narrator support and harsher world-roleplay hooks.
  • Shared AI Stack: Uses the same DwemerDistro backbone as CHIM, but with Kenshi-side setup and launch requirements.

Recommended First Run

  • Use OpenRouter first for the LLM path.
  • Install only the DwemerDistro components your hardware can support.
  • Start with RE_Kenshi and KenshiLib, then expand after base conversations work.

Next Step

The STOBE setup is shorter than CHIM's, but it still depends on DwemerDistro and on launching RE_KENSHI rather than regular Kenshi.
