STOBE Installation

Download STOBE plugin on Nexus Mods - get the Stobe file.

Open the installation video on YouTube

This guide uses OpenRouter for the language model because it is the easiest first setup.

Add credit to OpenRouter, then create an API key.

It is by far the easiest way to setup the mod for the first time!

You can use alternate AI services later once you get it working.

Installing DwemerDistro

  • Ensure you have virtualization enabled in your PC BIOS menu (Here is a good guide if you are having issues).
  • Open Control Panel - Programs and Features, and click Turn windows features on or off.
  • Ensure you have Virtual Machine Platform, Windows Hypervisor Platform, and Windows Subsystem for Linux enabled.
  • Restart your PC.
  • Download the DwemerDistro from the mod page.
  • Extract the .exe anywhere on your PC.
  • Run the DwemerDistroInstaller.exe.
  • Simply follow the installation guide and wait for it to finish.
  • Leave Create desktop shortcut enabled, and click finish once it is complete.
  • Run the DwemerDistro.exe shortcut on your desktop.

Set Up STOBE in DwemerDistro

  • On Quickstart Step 2, click Update Distro.
  • Wait for the update to finish, then click Next.
  • Step 3 opens with no mods selected.
  • Select STOBE, then click Install Selected Mods.
  • Wait for STOBE to finish installing before continuing.
  • Step 4 lists the components detected by DwemerDistro.
  • Review the green status checks, then click Continue to Start Server.

Component Installation Guide:

  • If you have a powerful NVIDIA GPU install CUDA, Minime&TXT2VEC (GPU) & Chatterbox.
  • If you have a less powerful NVIDIA GPU install CUDA, Minime&TXT2VEC (GPU) & Pocket-TTS (GPU).
  • If you have an AMD GPU, download Minime&TXT2VEC (CPU) & Pocket-TTS (CPU).

For Pocket TTS and Chatterbox you must setup a Hugging Face account and accept the terms of service for it here:

Pocket TTS: https://huggingface.co/kyutai/pocket-tts

Chatterbox: https://huggingface.co/ResembleAI/chatterbox

  • After Quickstart finishes, select STOBE on the launcher Mods page.
  • Click STOBE Webpage to open the server website.
  • If the server is stopped, confirm the prompt to start it first.

STOBE Web Quickstart

Complete the Quickstart Menu in your browser:

To run your own language model, use the launcher's LLM Studio component. Follow the Local LLM Guide to download, load, test, and connect it inside DwemerDistro.

  • Use an OpenRouter Key, Player2, or the guided local-model setup in Quickstart.
  • Select your TTS Connector.
  • Leave Parakeet selected for local speech-to-text, or choose another STT provider later.

QuickStart fills the Standard, Fast, Powerful, and Experimental response choices for the default and player-faction profiles. You can change them later from the profile editor.

OpenRouter is optional. To use another provider directly, save the rest of QuickStart and follow Use Your Own LLM Provider.

  • Click Save and Continue.

STOBE Mod Setup

DOWNLOAD AND INSTALL THESE REQUIRED MODS!

  • RE_Kenshi
  • KenshiLib
  • Download the Stobe file in the downloads page.
  • Install it with your mod manager of choice.
  • Or manually place it within C:\Program Files (x86)\Steam\steamapps\common\Kenshi\mods.
  • Now you are ready to play!

In-game Setup

  • Ensure that DwemerDistro is running and start RE_KENSHI (DO NOT START REGULAR KENSHI).
  • Ensure STOBE is enabled in the mod manager.
  • Once in game (no newgame required) follow the popup message.
  • Try talking to an NPC using the chat hotkey. You should get a response.

Well done, you have the mod installed!

READ ME

For normal server updates, restart the DwemerDistro launcher and click Update STOBE on the STOBE Mods page. Install the latest STOBE file from Nexus when a new game-plugin file is included. You do not need to reinstall DwemerDistro unless the release notes say so.

Quickstart And Updates

Use the Quickstart shortcut on the server home page when you need to return to setup.

  • First check: Send a typed message to a nearby NPC and confirm a reply. Then test voice playback and microphone input.
  • Keep the pair together: Update the game plugin and server to matching versions. Keep your personal settings file when replacing the main mod files.
  • Separate characters: See Playthrough Saves before switching to another character or campaign.
