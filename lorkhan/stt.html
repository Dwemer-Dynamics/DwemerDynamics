Speech-to-Text

Speech-to-text turns microphone audio into the text sent to the language model.

Set Up Speech-to-Text

Parakeet is the initial local transcription choice. Install and start it in DwemerDistro, then open Configuration → STT.

  1. Connect OpenMW once if the page asks for an installation.
  2. Select Parakeet and use the address of your running service. Keep the Distro-provided address for its managed component.
  3. Save the connector.
  4. Use Test to transcribe the page's fixed sample. Test also saves the current settings. This checks the service, not your microphone.
  5. Then perform the microphone test below.

STT is shared across this installation, not assigned per NPC profile. Switching services here changes the active transcription service. Player TTS is separate and need not be enabled to use a microphone.

Other Transcription Services

The picker groups Deepgram and Parakeet as recommended options. It also offers Whisper (OpenAI), Local Whisper, Gemini, Azure and Inworld, alongside the disabled option.

  1. Select the service to reveal its fields.
  2. For hosted services, configure credentials and the model, region or language fields shown. For local services, supply the reachable address.
  3. Save and test before recording in game. Hosted tests may incur charges.
  4. If the test fails, inspect the service error before changing microphone sensitivity.

Selecting Local Whisper does not install or start its runtime. Features differ between providers; follow the fields shown for the selected driver.

Record a test

  1. Check the recording device in the in-game LORKHAN Scripts settings.
  2. Look at the intended NPC and confirm the target.
  3. Hold your Voice Chat binding, say a short sentence and release it.
  4. Check whether a transcript appears before investigating the NPC response.

Check Windows microphone access and input levels if no audio is recorded.

Open microphone

Use the Open Microphone binding for voice-activated recording. Use the separate mute control when you want to pause listening temporarily. Avoid speaker feedback by using headphones while testing.

Confirm recording and mute state directly. Turning AI interaction off is not the same as turning the microphone off.

Find the failed stage

  • No recording: Check the device, binding, permissions and mute state.
  • Recording but no transcript: Check Parakeet and its connector address.
  • Transcript but no reply: Check the target, AI interaction and language model.
  • Reply but no voice: Follow the TTS guide.

Include the approximate test time when collecting diagnostics.
