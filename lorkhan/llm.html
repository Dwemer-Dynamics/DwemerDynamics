Large Language Models

A language model generates the text of a reply. Its voice is configured separately.

Choose a provider

Start in Quickstart, or edit the LLM connectors in Configuration. Use your provider’s model name, endpoint and credentials. A model displayed in a saved connector still needs to be available to your account.

Hosted services may charge per request. Review the provider’s pricing and data policy before sending game dialogue.

Profile model slots

  • Standard: The normal conversation choice.
  • Fast: A separate model slot for quicker replies.
  • Powerful: A separate slot for more demanding requests.
  • Experimental: A slot for trying another model.

Assign connectors to these slots in Profiles and save. In Text Chat and Interact, LLM model selects the slot by name; it does not create or download a model. Selecting Fast cannot speed up a slow model if both slots use the same connector.

Other model jobs

Profiles also contain assignments and options for tasks such as diaries and fallback responses. Check these before expecting background features to work. A fallback needs a usable connector; it is not a replacement for fixing invalid credentials.

Prompt guidance

Use Profile Prompt for guidance shared by characters on that profile. Use an NPC’s Prompt Head Override only for character-specific instructions.

Keep guidance concise. Longer prompts, large context and long requested replies can increase latency and cost. LORKHAN uses Markdown-oriented prompting; do not paste XML response templates from another mod.

Test one change at a time

Send the same short request after changing one model assignment. If a reply appears in the server but arrives late as audio, test the voice service separately before blaming the language model.

For local models, follow the Local LLM Guide.
