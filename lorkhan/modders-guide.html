Modders Guide

Start with supported data customization. Native or Lua changes need a matching client build.

NPC biographies

Use the server’s NPC biography tools for reusable character information. Base IDs identify game records; live reference IDs distinguish individual actors. Keep identity fields accurate rather than using display names as unique keys.

Use the current importer’s format and test a small import before processing a full mod. Back up existing data first. Do not assume a CSV from another game can be imported unchanged.

Voice presets

Biography data can include Voice ID and supported voice-filter presets. Verify the imported values in an activated NPC’s editor, then preview the voice with the intended connector.

Only distribute audio and character assets you have permission to share. A local sample path on your development PC is not a portable voice asset.

World knowledge

Add relevant setting information through Oghma’s knowledge tools. Keep each article focused on one topic and test retrieval in context. Avoid mixing private NPC memories into general world knowledge.

Reference groups

Use editable reference groups for multiple references that intentionally represent the same character. Do not merge unrelated actors just because their names or base records match.

Source and builds

The LORKHAN repository contains the native bridge, Lua mod and build instructions. LorkhanServer contains the server. Both use GPL-3.0 licensing; third-party components retain their own notices.

Use the matching beta source package and build instructions when rebuilding a release. Keep the pinned engine, native bridge and Lua files together. Do not distribute Bethesda game data.
