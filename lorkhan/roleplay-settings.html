Roleplay Settings

Configure character development and context through profiles, then inspect individual NPCs when needed.

Profiles and memories

Dynamic Profile allows character profile updates. Middle Term Memory and Short Term Memory control the corresponding memory features for a profile.

Enable only the behaviour you want, save the profile and test with an NPC assigned to it. Use the in-game Dynamic profiles menu for manual requests; automatic updates depend on the profile settings.

Relationships

Morrowind disposition is on a 0–100 scale. In-game persuasion and bribes can change it, and supported AI interactions can also affect it. Treat the live game value as the reference when checking a mismatch.

Inspect the NPC’s relationships and recorded interactions in the server. A biography’s initial relationship descriptions are not the same as a history of conversations with your current character.

Diaries

Profile options include Auto Diary, Auto Diary Wait, Physical Diary and Include Latest Diary Entry. Use these to control generation after sleep or wait, readable in-game diary output, and whether the latest entry is used in response context.

Diary generation needs a working model assignment. Check the server’s diary view before assuming an automatic trigger has produced an entry.

Narrator and player

Open Configuration → Narration to configure the narrator separately from ordinary NPCs. Review its prompt, voice and event settings before enabling frequent narration. Use Configuration → Player for player speech; changing an NPC profile’s voice does not configure the player voice.

Oghma Infinium

Oghma supplies world knowledge to character prompts. Review the knowledge articles and use Oghma Result Limit in Global Settings to control how many matching articles are included.

Keep articles relevant and concise. World knowledge should describe the setting; a character’s private memories belong in that character’s history.

Repeated names and reference groups

Two actors called Hlaalu Guard do not need to share a profile. Check reference IDs when reviewing their memories. Reference groups are for deliberate exceptions, such as several game references representing one named character.

Do not group all guards together simply because their displayed names match.
