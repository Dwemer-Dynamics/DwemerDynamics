LORKHAN

AI conversations, voices and character memories for The Elder Scrolls III: Morrowind, powered by a dedicated OpenMW build.

LORKHAN 0.5.0 beta

This guide covers the 0.5.0 Windows beta. Keep your existing game installation and saves backed up. LORKHAN needs its matching OpenMW build, Lua files and LorkhanServer; it is not a plugin for the original Morrowind executable.

Start with the installation guide for requirements, beta availability and first-run setup.

Talk to characters

Use text or your microphone to speak to NPCs. LORKHAN uses nearby game context to inform replies, and plays generated speech with subtitles. Profiles let you choose models, voices and roleplay settings.

Vanilla dialogue speech can also read dialogue menu responses. Player speech is optional. See Text-to-Speech.

Memories and relationships

NPCs can remember conversations, keep diaries and develop their profiles. Separate actor references let two guards with the same name remain distinct characters. Editable reference groups can deliberately share a character profile.

See Roleplay Settings for memories, relationships and lore.

Interaction and actions

Open Text Chat and Interact to select dialogue mode, mood or model strength, view context history, and ask a character to wait. Supported NPC actions are controlled through the server Action Editor.

Director and Cheat modes are available, but they do not make every imagined action possible. Check the actions enabled for your setup before relying on a request.

Choose your setup

Use local or hosted AI services. Quickstart helps configure them; local services still need to be installed and running. Start with one working conversation before changing voices or adding other mods.
