LORKHAN

AI conversations, voices and character memories for The Elder Scrolls III: Morrowind, powered by a dedicated OpenMW build.

LORKHAN 0.5.0 beta

This guide covers the 0.5.0 Windows beta. Keep your existing game installation and saves backed up. LORKHAN needs its matching OpenMW build, Lua files and LorkhanServer; it is not a plugin for the original Morrowind executable.

Check the requirements and beta availability before first-run setup.

What LORKHAN does

What you can do with the beta, and where each feature is set up.

Talk to characters

Use text or your microphone to speak to NPCs. LORKHAN uses nearby game context to inform replies, and plays generated speech with subtitles. Profiles let you choose models, voices and roleplay settings.

Vanilla dialogue speech can also read dialogue menu responses. Player speech is optional. See Text-to-Speech.

All NPCs

LORKHAN activates eligible actors around the player, so conversations are not limited to a single hand-authored companion. Aim at a character before opening Text Chat and Interact; when there is no crosshair target, the menu can use a nearby NPC.

For example, speak to one Hlaalu guard, then another. The two references can keep separate histories despite sharing a name. Use deliberate reference groups only for several references that represent the same character.

Find, edit and assign characters →

Memories and relationships

NPCs can remember conversations, keep diaries and develop their profiles. Separate actor references let two guards with the same name remain distinct characters. Editable reference groups can deliberately share a character profile.

Memories, relationships and lore →

Interaction and actions

Open Text Chat and Interact to select dialogue mode, mood or model strength, view context history, and ask a character to wait. Supported NPC actions are controlled through the server Action Editor.

Director and Cheat modes are available, but they do not make every imagined action possible. Check the actions enabled for your setup before relying on a request.

The Action Editor →

Total AI Control

Choose a provider for dialogue, another for speech, and a separate microphone service. Profiles let groups of characters share choices without forcing every NPC to use one voice or model.

The four response slots—Standard, Fast, Powerful and Experimental—are selected from the interaction menu. A roleplay-heavy character can use a different profile from a character intended for short replies. Player and narrator speech have their own controls.

Assign and save profile choices →

Oghma, Narrator and Diaries

Oghma adds relevant world knowledge. The narrator can describe events or read books when enabled. Diaries give characters a written account of witnessed events and can be materialized as readable books.

These features depend on their settings and assigned services; they are not all activated by selecting a chat model. Follow Roleplay Settings to enable and test each feature.

Choose your setup

Use local or hosted AI services. Quickstart helps configure them; local services still need to be installed and running. Start with one working conversation before changing voices or adding other mods.
