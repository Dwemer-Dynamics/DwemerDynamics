Morrowind Settings

Open Options → Scripts → LORKHAN to configure the in-game controls.

Hotkeys

Open Options → Scripts → LORKHAN. Click a binding, then press the desired keyboard, mouse or controller button. Escape clears it.

  • Text Chat and Interact: Opens the focused text box and conversation options for the target. Type immediately and press Enter to send.
  • Voice Chat: Hold to record, then release to send the transcript to the selected NPCs.
  • Open Microphone: Toggles voice-activated chat.
  • Mute Open Mic: Temporarily pauses or resumes open-microphone recording.
  • Activate NPCs: Toggles the aimed NPC or activates nearby NPCs.
  • Stop AI Actions: Stops dialogue, recording and AI actions.

Read the bindings on your own installation: imported profiles or earlier choices can differ from another player’s keys. Do not look for a Skyrim MCM or Prisma panel; these are OpenMW Scripts settings.

Auto Activate

Enable Auto Activate automatically brings nearby eligible actors into LORKHAN. Interior and exterior activation distances control how far it searches in each environment.

Include Hostile NPCs and Include Creatures broaden eligible actor types. Activation is not the same as permission to perform every action, and it does not guarantee every nearby character will reply to every line.

For a missing actor, test the manual Activate NPCs binding while aiming at it, then check its entry on the server. Avoid increasing every distance while diagnosing one missing target.

Choose a target

Look at the NPC you want to address. LORKHAN prefers the eligible actor under the crosshair; without a crosshair target, it falls back to a nearby NPC.

Check the name shown in Text Chat and Interact before sending. Wait Here (90 seconds) asks the target to stop moving temporarily.

Dialogue mode and mood

Dialogue mode contains the available conversation modes and typed shortcuts. Use the shortcuts shown beside each mode rather than guessing a prefix. Director and Cheat are execution modes, not language model choices.

Mood changes delivery guidance. LLM model selects Standard, Fast, Powerful or Experimental from the current profile. Auto Chat is controlled through the modes menu.

  • Standard, Whisper, Close and Shout: Select how the message is addressed and heard.
  • Narrator: Send the request to the narrator.
  • Director and Cheat: Use the corresponding execution mode, subject to enabled actions.
  • Auto Chat: Control automatic player chat through the mode menu.
  • Inject Event: Add an event without asking for a chat response.
  • Inject & Chat: Add the event and request a response.

Dynamic profiles and history

Dynamic profiles sends the selected update request to the server and closes the menu. Check which NPC is targeted before requesting a character update.

Context history shows conversation context. Status HUD controls the optional status display, and Diagnostics helps investigate connection problems.

Hearing & Awareness

Hearing distances determine the audience for a conversation. They are separate from activation distances: an active NPC does not necessarily hear every line.

  • Interior / Exterior Hearing Distance: Listener ranges in game units. Indoor doors and outdoor distance fading can affect audibility.
  • Auto Hearing Radius (meters): Nearby hearing without door/path checks, still bounded by hearing distance. One metre is 70 game units.
  • Speech mode: Whispering and sneaking reduce the automatic allowance. Close mode does not use that allowance.

Use the available preset before choosing Custom values. Test with one nearby actor and one farther away so you can tell whether targeting or hearing is responsible.

Conversation & Microphone

  • Allow Combat Dialogue: Allows replies from actors in combat. Turning it off does not stop microphone recording or transcription.
  • Stop Dialogue in Combat: Stops dialogue and recording when an NPC attacks you.
  • Enable Combat Barks: Allows periodic combat shouts. Combat Bark Timer (seconds) starts at 30; server/profile settings also apply.
  • Pause autonomous dialogue: Separate controls cover menus, combat and sneaking.
  • Microphone ID: −1 uses the Windows default. Find device IDs in Diagnostics and restart recording to apply a change.
  • Open Mic Sensitivity: Higher values require louder speech.
  • Open Mic Silence (ms): Silence needed before a recording is submitted.

If a recording ends too early, review the silence setting. If room noise triggers it, check the device, input level and sensitivity. Test with headphones to avoid the NPC’s voice being recorded again.

Sound

Start with ordinary speech volume before changing spatial audio. These controls affect playback, not whether the model generates a response.

  • Audio Mode: Chooses directional/distance playback or mono. Realistic 3D and Mono + Effects use the custom distance curve; this is OpenMW playback, not Skyrim occlusion.
  • Head Voice Volume (%): Controls player and narrator volume relative to the voice boost.
  • Normal Distance Scale: Adjusts Normal 3D playback distance.
  • Advanced Distance Scale / Interior Dropoff / Exterior Dropoff: Adjust Realistic 3D and Mono + Effects.
  • Clip Start / Clip End: Trims milliseconds from generated clips. Leave at zero unless fixing a specific clip problem.
  • Read Dialogue Aloud: Speaks vanilla dialogue menu responses.
  • Read Books Aloud: Uses the narrator voice; closing the book stops it.

The audio pause setting affects playback while the game is paused. Keep the default unpaused playback if you want speech during dialogue menus. Player TTS is configured separately on the server.

AI Agents and Display

  • Enable AI actions: Permits the game-side action path; the server still controls which actions are allowed.
  • Show Status HUD: Shows the optional status overlay. It is not required for dialogue.
  • Connection Timeout: Defaults to 30 seconds; accepted range is 15–300. A larger timeout does not repair a wrong address or pairing key.
  • Chat History Rows: Controls the recent lines kept in the chat display.

The interaction menu also provides Context history and Diagnostics. These are better first checks than resetting every Scripts setting.
