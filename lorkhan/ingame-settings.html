Morrowind Settings

Open Options → Scripts → LORKHAN to configure the in-game controls.

Hotkeys

Set Text Chat and Interact to a comfortable key. The text field is focused when the menu opens, so you can type immediately and press Enter to send.

Use the separate voice recording and open-microphone bindings for speech input. Check your actual bindings in the Scripts menu rather than relying on a key from another player’s setup.

Choose a target

Look at the NPC you want to address. LORKHAN prefers the eligible actor under the crosshair; without a crosshair target, it falls back to a nearby NPC.

Check the name shown in Text Chat and Interact before sending. Wait Here (90 seconds) asks the target to stop moving temporarily.

Dialogue mode and mood

Dialogue mode contains the available conversation modes and typed shortcuts. Use the shortcuts shown beside each mode rather than guessing a prefix. Director and Cheat are execution modes, not language model choices.

Mood changes delivery guidance. LLM model selects Standard, Fast, Powerful or Experimental from the current profile. Auto Chat is controlled through the modes menu.

  • Standard, Whisper, Close and Shout: Select how the message is addressed and heard.
  • Narrator: Send the request to the narrator.
  • Director and Cheat: Use the corresponding execution mode, subject to enabled actions.
  • Auto Chat: Control automatic player chat through the mode menu.
  • Inject Event: Add an event without asking for a chat response.
  • Inject & Chat: Add the event and request a response.

Dynamic profiles and history

Dynamic profiles sends the selected update request to the server and closes the menu. Check which NPC is targeted before requesting a character update.

Context history shows conversation context. Status HUD controls the optional status display, and Diagnostics helps investigate connection problems.

Audio and automatic dialogue

Review the microphone, speech playback, hearing and awareness controls in Scripts. Combat bark interval starts at 30 seconds; profile and server settings also determine whether automatic speech is eligible.

Stop AI Actions is an emergency action control. Microphone capture, AI interaction and speech playback are separate controls; check each one when troubleshooting.

For menu dialogue speech and player TTS, see Text-to-Speech.
